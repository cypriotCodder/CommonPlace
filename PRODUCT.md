# Commonplace

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

A personal, local study space for a computer science graduate learning from their own books. Connect source passages to applied problems and recall practice. The learner selects a whole book; AI discovers useful ideas without requiring the learner to preselect valuable sections.

## Operating context

Next.js, React, TypeScript, and local SQLite. Existing PDF/EPUB extraction, saved passages, notes, practice, and recall progress persist locally. The optional n8n integration is separate from the planned subscription-chat exchange: export book text, use Gemini or Claude chat, import discoveries, generate material, review and accept.

## Confirmed layout direction

Three destinations: Library for uploading/managing books, AI Workspace for importing and reviewing output, and Study for passage → applied challenge → recall practice. The user requested a clickable in-app design preview on 31 October 2026. Existing editorial visual identity remains authoritative in DESIGN.md.

## Constraints and principles

- Preserve user data, exact quotations, attribution, and existing learning behavior.
- Distinguish AI-reported coverage, validated sources, accepted material, and learning activity.
- Show source evidence and require review before accepting generated material.
- Keep file exchange explicit and local until the learner uploads to their chosen chat.
- Use keyboard-accessible, responsive interfaces with accurate feedback.

## Evidence and open scope

The existing app and authored extraction fixtures are available. Preview data must be labeled as illustrative. Whole-book subscription exchange is planned, not implemented. Apple Books integration is exploratory. Hands-on coding exercises, OCR, freshness research, and automatic chat control are outside the current preview.
